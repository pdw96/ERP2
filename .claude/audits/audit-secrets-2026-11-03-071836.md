## 부적합 목록

### NC-6 · 되돌림과 배포 빌드의 실패 로그가 「오류 코드만」이 아니라 DB 서버 메시지까지 남긴다
- 위치: `src/db/reset-request.ts:28`, `scripts/migrate.ts:30` → `src/db/status.ts:40-41`
  - 문서 쪽: `docs/slices/2-기준정보/design.md:43,173`, `docs/deploy.md:80-83`
- 증상:
  - 설계 ② 는 「방문자가 넣은 글자는 로그에 남지 않는다 — 실패 로그는 오류 코드만 남긴다」라고 한다. ④ 도 「실패는 오류 코드만」이라고 한다.
  - 그런데 두 새 경로는 `describeFailure` 를 쓴다. 이 함수는 DB 서버 오류면 `코드 등급 메시지` 를 남긴다.
  - `deploy.md:80-83` 은 메시지가 남는다고 적었다. 문서끼리도 어긋난다.
  - 시험 `reset-request.test.ts:41-53` 의 이름은 「오류 코드만」이지만, 네트워크 오류(코드 경로)만 넣는다. 서버 오류 경로는 시험하지 않는다.
- 근거:
  - 전제: PR B 안에서는 지금 방문자 글자가 이 메시지에 실리는 길이 없다. 되돌림은 고정된 샘플만 넣고, 첫 마이그레이션은 빈 테이블을 만든다.
  - 실리는 때 ① 방문자 데이터가 쌓인 운영 DB 에 뒤 PR 의 마이그레이션이 형변환이나 제약을 걸다 실패할 때. 예: `invalid input syntax for type …: "<방문자 글자>"` 가 빌드 로그에 남는다.
  - 실리는 때 ② PR C-E 의 쓰기 경로가 「오류 코드만」을 믿고 같은 함수를 쓸 때.
  - 이것은 회차 3 OB-1 이 경고한 자리이고, 요구사항 76-77줄이 이 회차에 맡긴 질문이다.
- 심각도: **보통**. 막는다고 믿는 회귀를 막지 않는다. 지금 새는 값은 없다.
- 제안(둘 중 저자가 고른다):
  - (a) 방문자 데이터에 닿는 경로(되돌림, 빌드, 앞으로의 쓰기)는 `코드 등급` 만 남긴다. 메시지는 질의가 고정된 `/health` 에만 남긴다(audit-ops NC-3 의 결정은 유지). 서버 오류를 넣는 시험을 더한다.
  - (b) 설계 ②④ 와 deploy.md 의 문구를 실제 동작에 맞춘다. 그리고 PR C-E 의 쓰기 경로에 「코드만」을 요구로 적는다.

## 확인불가 항목

### U-8 · 미리보기 빌드의 `DATABASE_URL_UNPOOLED` 가 미리보기 분기 DB 를 가리키는가
- 체크 항목: 2
- 위치: `scripts/migrate.ts:10`, `docs/schema.md:61-62,65`, 요구사항 성공 기준 7
- 판정하려면:
  - 이 가지의 미리보기 빌드가 돈 뒤, Neon 커넥터(읽기 전용)로 본다.
    - **운영 `main` 분기**: `select to_regclass('public.items'), to_regclass('drizzle.__drizzle_migrations')` 가 둘 다 null.
    - **`preview/claude/practical-sagan-55glr8` 분기**: 같은 질의에 테이블이 있다.
  - 또는 Vercel 환경변수 화면에서, 미리보기 가지마다 `DATABASE_URL_UNPOOLED` 가 가지별 값으로 덮어써졌는지 본다.
  - 코드로 판정되게 하려면, 두 값이 같은 endpoint 가 아닐 때(호스트에서 `-pooler` 를 뺀 값이 다를 때) 빌드를 멈추는 줄을 `migrate.ts` 에 더한다.
- 누가 줄 수 있는가: 메인 세션(Neon 커넥터, Vercel 커넥터), 또는 저자
- 틀렸을 때 잃는 것: **높음**. 머지 안 된 마이그레이션과 첫 샘플 넣기가 데모 DB 에 적용된다. DB 는 배포 되돌리기로 돌아오지 않는다(`deploy.md:124`).
- 근거가 오기 전에는 통과로 세지 않는다. 지난 U-2 는 분기가 만들어진 것만 봤다. 어느 변수가 그 분기를 가리키는지는 보지 않았다.

### U-9 · 미리보기 분기와 운영 분기의 DB 접속 비밀번호가 같은가 (회차 3 OB-3)
- 체크 항목: 2
- 위치: `docs/slices/1-기반/requirements.md:81`, `docs/slices/2-기준정보/requirements.md:76-77`, `docs/deploy.md:16-18`
- 무엇: 요구사항이 이 조각에서 답할 질문으로 적었으나, 설계와 PR B 에 답이 없다. 미리보기 보호가 꺼져 있다. 그래서 같은 비밀번호라면 미리보기에서 접속값이 한 번만 새도 운영 DB 전권으로 이어진다. 그 전권은 행 상한과 서버 검사를 우회하고 테이블을 지울 수 있다.
- 판정하려면: 저자가 Neon 콘솔의 두 분기 **Connect** 화면에서 비밀번호 부분이 같은지 「같다/다르다」만 답한다. 값은 붙이지 않는다. Neon 커넥터는 읽기 전용 모드라 접속 문자열을 주지 않는다.
  - 같으면: 분기마다 역할을 따로 두거나 비밀번호를 바꾸는 방안, 아니면 받아들이는 저자 판정(ADR)이 필요하다. 받아들이지 않으면 부적합이고, 심각도는 보통 후보다.
- 누가 줄 수 있는가: 저자
