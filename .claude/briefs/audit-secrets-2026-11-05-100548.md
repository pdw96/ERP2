+## 대안
+

+3. **Neon-Managed 연동으로 바꾼다** — Git 가지를 지우면 다음 미리보기 배포 때 DB 가지를 지운다. 연동을 다시 잇고 환경변수가 바뀐다.
+4. **Vercel 의 미리보기 보관 기한을 줄인다** — 「최근 20개」 보존이 있어 이 레포에서는 효과가 없다.

+  countries: readonly CodeOption[],

+ * 숨은 칸에 코드와 불러온 때의 버전을 둔다.

+export function itemSheetRow(item: {
