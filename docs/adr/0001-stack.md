# ADR 0001 — 스택: TypeScript · Next.js · PostgreSQL

- 날짜: 2026-11-02
- 상태: 정함
- 조각: 기반

## 맥락

포트폴리오를 보는 사람은 생산관리 · 재고관리 · 출하관리 자리의 채용 담당자다(저자의 지원 직무). 그들은 코드보다 데모
화면과 업무 흐름을 본다. 데모는 무료 요금제로 늘 열려 있어야 한다(저자가 정함). 저자는 코드를 거의 읽지 않으므로 스택
고르기는 업무에 영향이 없는 기술 결정이다 — 저자가 「직무에 맞춰 추천」을 청했다.

## 대안

1. **TypeScript · Next.js · PostgreSQL** — 화면과 서버를 한 앱으로 짓는다. 무료로 늘 켜진 배포처(Vercel)가 있다.
2. **Java Spring Boot · React · PostgreSQL** — 국내 기업용 시스템의 표준이라 개발자 채용에서 알아본다. 무료 서버는 쉬다가
   깨어나느라 첫 접속이 수십 초 늦고, 늘 켜 두려면 돈이 든다. 앱이 둘(서버 · 화면)이라 배포도 둘이다.

## 결정

1 을 고른다. 보는 사람이 화면을 보는 자리라 스택의 이름값보다 데모가 늘 빠르게 열리는 것이 크고, 비용 0원에 맞는다.
DB 는 업무 데이터의 관계(품목 · 수불 · 전표)를 다루므로 관계형인 PostgreSQL 로 한다.

## 결과

- 개발자 자리에 낼 때 Java 경험을 보이지는 못한다 — 이 포트폴리오의 목적(현업 자리 · AI 활용) 밖이다.
- 화면 · 서버 · 시험을 한 언어로 다룬다.
