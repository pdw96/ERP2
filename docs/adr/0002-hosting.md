# ADR 0002 — 배포처: Vercel · Neon

- 날짜: 2026-11-02
- 상태: 정함
- 조각: 기반

## 맥락

ADR 0001 의 스택을 무료 요금제로 늘 열어 둘 곳이 필요하다. PR 마다 저자가 화면을 미리 볼 수 있어야 하고(저자는 화면으로
판단한다), 미리보기가 데모 DB 를 건드리면 안 된다.

## 대안

1. **Vercel(앱) · Neon(DB)** — Vercel 은 Next.js 를 만든 곳이라 설정이 거의 없고, PR 마다 미리보기 주소를 붙이며, 이전 배포로
   곧바로 되돌릴 수 있다. Neon 은 쉬다가 1초 안팎에 깨어나고, PR 마다 데이터를 갈라 쓰는 분기 DB 를 무료로 준다.
2. **Vercel · Supabase** — Supabase 무료 DB 는 한 주 동안 접속이 없으면 멈추고 손으로 다시 켜야 한다. 채용 담당자가 열었을
   때 멈춰 있을 수 있다.
3. **Render · Fly.io** — 무료 서버가 쉬다가 깨어나는 데 수십 초가 걸리거나 무료 요금제가 없다.

## 결정

1 을 고른다. PR 미리보기는 Neon 분기 DB 를 쓰고, 운영 DB 는 `main` 배포만 쓴다.

## 결과

- Vercel Hobby 는 비상업 용도만 허용한다 — 개인 포트폴리오라 맞는다.
- 무료 요금제의 한도(Neon 저장 0.5GB 등)를 넘으면 다시 정한다.
- 가입과 GitHub 연결은 저자가 한다.
