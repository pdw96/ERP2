# ADR 0004 — 데모는 누구나 쓰고 매일 밤 되돌린다

- 날짜: 2026-11-02
- 상태: 정함
- 조각: 기준정보

## 맥락

조각 「기준정보」부터 데모에 등록 · 수정 화면이 붙는다. 로그인은 조각 「인사」에서야 생긴다. 채용 담당자가 직접 눌러 보게
할지, 누가 데이터를 망치면 어떻게 할지를 정해야 한다(「기반」 감사 회차 1 의 OB-4).

## 대안

**누가 쓰나** — 저자에게 물어 정했다(2026-11-02).

1. 누구나 등록 · 수정하고, 매일 밤 샘플 데이터로 되돌린다.
2. 보기만 하고, 고치려면 데모 비밀번호를 넣는다.
3. 누구나 쓰고, 되돌리지 않는다.

**되돌림을 무엇이 부르나** — 업무에 영향이 없는 기술 결정이라 Claude 가 정했다.

1. Vercel Cron 이 하루 한 번 앱의 입구를 부르고, 앱이 DB 를 되돌린다. 입구는 Vercel 이 넣어 주는 비밀값(`CRON_SECRET`)을 가진
   요청만 받는다.
2. GitHub Actions 예약 실행이 DB 에 직접 접속해 되돌린다 — DB 접속 정보를 GitHub 비밀값에도 두어야 한다.

## 결정

누가 쓰나는 1(저자 판정), 되돌림은 1 을 고른다. 예약 시각은 한국 시간 새벽(방문이 가장 적을 때)이다.

## 결과

- 채용 담당자가 로그인 없이 직접 등록 · 수정해 볼 수 있다.
- 같은 날 안에는 누가 남긴 글이 다른 방문자에게 보일 수 있다 — 다음 되돌림까지다.
- DB 접속 정보는 Vercel 한 곳에만 있다. 저자가 Vercel 환경변수 `CRON_SECRET` 을 넣는다(`docs/deploy.md`).
- Vercel Hobby 의 예약 작업은 하루 한 번 · 정한 시 안의 어느 때에 돈다. 더 자주 되돌려야 하면 다시 정한다.
- 로그인이 생기는 조각 「인사」에서 이 결정을 다시 본다.
