# ADR 0032 — 작업장의 코드 체계와 공정 잇기

- 날짜: 2026-11-18
- 상태: 정함
- 조각: 메뉴 「작업장 등록」(묶음 「라우팅」)

## 맥락

메뉴 「작업장 등록」을 시작하며 묶음 「라우팅」의 열린 업무 결정을 모았다. 작업장코드는 품목별 라우팅 · 작업장 능력 · 작업지시 · 생산실적이 모두
가리키므로 앵커볼트 「업무 용어 · 코드 체계」다. 작업장과 공정을 어떻게 잇는지(작업장 하나에 공정 하나 · 여럿), 작업장에 담을 칸, 등록한 작업장의
공정을 바꿀 수 있는지도 열려 있었다. 생산은 저자가 잘 아는 영역이라 선택지를 먼저 보이고 추천을 붙여 물었다(2026-11-18).

## 대안

- **작업장코드의 꼴** — (가) 사람이 넣는 영문 약어(`DA-1` · `WB-L2`, 공정코드와 같은 방식), (나) 저절로 붙는 일련번호(`WC-01`, 창고 `WH-01` 과 같은 꼴),
  (다) 공정코드 뒤에 일련을 저절로 붙인다(`DA-01`, 작업장 하나에 공정 하나일 때만).
- **작업장과 공정** — (가) 작업장 하나에 공정 하나(라우팅에서 공정을 고르면 그 공정의 작업장만 후보), (나) 작업장 하나에 공정 여럿(작업장에 할 수
  있는 공정 목록을 붙인다).
- **작업장의 칸** — (가) 코드 · 작업장명 · 공정 · 비고 · 사용 여부만, 능력 · 설비 · 재공 창고 · 외주 구분은 그 칸을 읽는 메뉴에서 정한다, (나) 재공
  창고 같은 칸까지 지금 넣는다.
- **등록한 작업장의 공정** — (가) 바꾸지 않는다(설비가 다른 공정을 하게 되면 새 작업장을 등록하고 옛 것은 「사용 안 함」), (나) 수정 화면에서 바꿀
  수 있다.

## 결정

저자가 모두 (가)를 골랐다. Claude 의 추천과 같다.

1. **작업장코드는 사람이 넣는 영문 약어다** — 영문 대문자로 시작하고 영문 대문자 · 숫자 · `-` 2 ~ 10자. `-` 는 끝에 오거나 둘 잇달 수 없다(Claude 의
   기술 결정 — `DA-` · `D--A` 같은 실수를 막는다). 소문자를 대문자로 바꾸지 않고 꼴을 알린다. 등록한 뒤 바꾸지 않고, 지우지 않고 「사용 안 함」으로
   둔다(ADR 0031 과 같다). 공정보다 많아 `-` 로 라인 · 호기를 나눌 자리를 두었다.
2. **작업장 하나는 공정 하나를 한다** — 반도체 후공정 설비는 보통 한 공정 전용이고, 품목별 라우팅에서 공정을 고르면 작업장 후보가 좁혀지며, 능력계획의
   부하가 공정별로 모인다.
3. **작업장의 칸은 코드 · 작업장명(50자) · 공정 · 비고(500자) · 사용 여부 다섯이다.** 능력(가동 시간)은 「작업장 능력」, 설비는 후보 「설비 관리」(ADR
   0012), 재공 창고(생산실적이 자재를 어디서 꺼내 쓰나)는 「생산실적」, 사내 · 외주 구분은 후보 「외주」에서 정해 더한다.
4. **작업장의 공정은 등록한 뒤 바꾸지 않는다** — 뒤 메뉴(라우팅 · 작업지시 · 실적)에 남은 공정과 작업장이 어긋나지 않는다.

등록 화면은 「사용 중」 공정만 고르게 하고, 서버도 「사용 안 함」 · 없는 공정을 거절한다. 공정이 뒤에 「사용 안 함」이 되어도 그 작업장은 그대로 둔다
(Claude 의 기술 결정).
