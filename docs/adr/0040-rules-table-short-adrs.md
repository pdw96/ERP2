# ADR 0040 — 업무 규칙표와 짧은 ADR

- 날짜: 2026-11-25
- 상태: 정함 — ADR 0029 「한 일을 시작할 때」의 찾는 곳을 바꾼다. ADR 이 기록이라는 규칙(0024 · 0029)은 그대로다
- 조각: 모든 일

## 맥락

ADR 이 38개(약 215KB)로 쌓였고, 최근 것은 하나에 12KB 안팎이다. 17개가 앞 ADR 을 고치거나 덧붙여, 규칙 하나의 지금 모습을 알려면 여러 개를 이어 읽어야
했다. 착공할 때마다 이 사슬을 다시 읽으니 메뉴가 늘수록 읽는 양이 는다(2026-11-25 비판 검토 · 이슈 #66).

## 정한 것(저자 판정 2026-11-25)

1. `docs/rules.md` 「업무 규칙표」를 둔다 — 지금 지키는 업무 규칙을 모듈마다 한 줄씩, 근거 ADR 과 함께. 앵커볼트는 ★ 로 표시하고, 정하지 않은 것은
   맨 아래에 모은다. 살아 있는 문서다.
2. 착공할 때는 규칙표의 그 모듈 절과 「아직 정하지 않은 것」, `docs/status.md` 「넘긴 결정」의 그 메뉴 줄을 읽는다. ADR 은 까닭이 필요하거나 표에
   없을 때만 연다.
3. 업무 규칙을 정하거나 바꾼 PR 은 규칙표의 그 줄도 고친다.
4. ADR 은 결정과 까닭만 짧게(2KB 안팎) 쓴다. 대안 비교 · 논의 · 예시는 PR 본문에 둔다.

## 결과

- 착공 때 읽는 양이 ADR 수와 상관없이 규칙표의 한 절(몇 KB)로 묶인다.
- 처음 채운 규칙표는 ADR 0003 ~ 0038 에서 뽑았다. 앵커볼트 줄은 저자가 보고 머지했다.
- 규칙표와 ADR 이 어긋나면 ADR 이 근거다 — 규칙표를 바로잡는다.
