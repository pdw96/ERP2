## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **재고 계산은 한 곳이다** — 수불을 남기는 길은 `src/db/stock.ts` 의 저장 하나다. 화면 · 뒤 조각이 잔액 표를 따로 고치지 않는다.
- **잔액 = 수불 줄의 합** — 수불 줄을 쓰는 같은 트랜잭션에서 잔액을 고친다. 품목 · 창고 · LOT · 상태마다 잔액이 그 키의 수불 줄 합과 같다.
  수불 줄은 고치거나 지우는 길이 없다.
- **음수가 없다** — 잔액은 0 밑으로 가지 못한다(DB 검사도 막는다). 줄이는 수불은 (일자, 등록 차례)로 세운 누계에서 넣는 날짜 뒤의 가장 작은
  누계를 넘지 못한다 — 지난 날짜로 넣어도 그 뒤 어느 때든 0 밑으로 가지 않는다. 거절하면 줄마다 모자란 수량을 보인다.
- **전표 단위** — 한 전표의 줄이 하나라도 틀리면 그 전표의 줄 · 잔액 · 번호 일련 · LOT 일련이 하나도 바뀌지 않는다.
- **동시에 저장해도** 같은 재고를 두 번 쓰지 않는다 — 잔액 행을 정한 차례로 잠그고 본다(ADR 0018).
- **취소** — 원래 전표의 반대 수량으로 새 전표가 생기고 원래 전표에 「취소됨」이 붙는다. 한 전표는 한 번만 취소되고, 취소 전표는 취소되지
  않는다. 취소도 음수 검사를 지난다.
- **상태** — 불량창고 재고는 불량이고, 불량창고 밖에서 상태가 검사대기인 재고와 함께 가용에서 빠진다. 수불관리의 출고 · 이동은 불량창고와
  검사대기 재고를 내보내지 않는다. 이동은 상태 칸을 그대로 싣는다. 이 조각의 입고 · 늘리는 조정은 늘 「가용」이다.
- **LOT** — LOT 관리 품목의 줄에는 LOT 가 반드시 있고, 끈 품목의 줄에는 LOT 가 없다. 사 오는 품목(원자재 · 부자재 · 소모품)의 입고는 LOT 를
  비우면 거절한다. 만드는 품목(반제품 · 완제품)의 입고에서 비운 LOT 는 그 품목의 규칙(없으면 유형의 기본 규칙)으로 수불 일자의 번호를 받는다. 저절로 붙일 번호가 그 품목에 이미 있으면 다음 일련으로 넘어간다. 수불이 있는 품목은 LOT 관리와
  단위가 바뀌지 않는다.
- **단위** — 넣은 수량은 넣은 단위의 자릿수, 쌓는 수량은 품목 단위의 자릿수를 넘지 못한다(반올림하지 않는다). 기준이 다른 단위로는 넣지
  못한다. 단위의 기준 · 배수는 등록 뒤 바뀌지 않고, 자릿수를 줄이는 것은 그 단위의 수량이 다 맞을 때만 된다.
- **번호** — 전표 `IV-YYYYMMDD-NNN` · 실사 `PI-YYYYMMDD-NNN` 은 날짜마다 겹치지 않는다(DB 의 유일 제약). LOT 번호는 품목 안에서 같은
  번호가 같은 LOT 다.
- **일자** — 미래 일자는 서버가 거절한다(한국 시각의 오늘이 기준).
- **실사** — 확정은 확정하는 순간의 장부와 견주고, 차이가 없으면 조정 전표를 만들지 않는다. 확정한 실사는 바뀌지 않는다. 창고 하나에 작성
  중인 실사는 하나다.
- **되돌림 · 상한** — 매일 밤 되돌림이 새 표를 다 비우고 샘플로 채운다. 표마다 등록 상한이 있어 누가 끝없이 넣어도 무료 저장 한도에
  닿지 않는다. 넣은 글자(비고 · LOT 번호)는 로그에 남지 않는다 — 실패 로그는 오류 코드만.

**보장하지 않는 것(알려진 한계)**

- 할당 — 이 조각에는 없다(하지 않을 일 1). 가용재고에 할당이 빠져 있다.
- 실사 중의 정확함 — 실사를 연 뒤 그 창고에 수불이 있으면 실물 수량과 확정 때 장부가 어긋날 수 있다. 경고만 하고 막지 않는다(ADR 0015).
- 같은 날 안의 장난 — 누가 엉뚱한 수불을 넣으면 그날 밤 되돌림까지 다른 방문자에게 보인다(ADR 0004).
- 계획 정보(안전재고 · 최소량 · 배수)의 자릿수 — 단위의 자릿수를 따르지 않고 소수 셋째 자리 그대로다(ADR 0017 결과).
- 조회의 빠르기 — 수불부 · 이력은 등록 상한 안에서 빠르면 된다. 상한을 크게 올리는 조각에서 다시 본다.
- 이 조각 앞의 배포로 되돌렸을 때의 매일 밤 되돌림 — ① 끝 문단대로 끈다.
- 뒤 조각의 수불 유형(구매입고 · 생산입고 따위) — 그 조각이 더하고, 이 조각의 규칙을 따른다.

## ③ 받는 입력

서버가 받는 입력이다. 화면의 검사를 건너뛴 요청도 같은 규칙으로 거절하고, 어느 칸(줄)이 왜 틀렸는지 보인다.

**수불 전표(PR C)**

| 칸 | 받는 값 |
|---|---|
| 일자 | `YYYY-MM-DD`, 한국 시각의 오늘 이하 |
| 유형 | `MOVE_TYPE` 의 `IN` · `OUT` · `XFER` · `ADJ` |
| 사유 | 조정이면 반드시 — `ADJ_REASON` 의 「사용」인 값. 다른 유형이면 비어야 한다 |
| 비고 | 비우거나 200자까지 |
| 줄 | 1 ~ 100줄 |

| 줄의 칸 | 받는 값 |
|---|---|
| 품목 | 「사용」인 품목 코드 |
| LOT | LOT 관리 품목: 입고 · 늘리는 조정은 영문 · 숫자 · `-` · `_` · `.` 1 ~ 30자 — 반제품 · 완제품만 비워도 된다(저절로), 출고 · 이동 · 줄이는 조정은 그 창고에 잔액이 있는 LOT. LOT 관리를 끈 품목: 비어야 한다 |
| 창고 | 입고 · 출고 · 조정은 하나, 이동은 보내는 창고 · 받는 창고(서로 달라야). 「사용」인 창고. 출고 · 이동의 보내는 창고는 불량창고가 아니다 |
| 수량 | 0 이 아닌 수. 입고 · 출고 · 이동은 0 보다 크고, 조정은 + · −. 넣은 단위의 자릿수 안 |
| 단위 | 비우면 품목 단위. 넣으면 품목 단위와 기준이 같은 「사용」인 `UNIT` 값 |

**취소(PR C)** — 전표 번호 하나. 취소되지 않은 원래 전표여야 한다.

**실사(PR E)** — 열기: 「사용」인 창고(작성 중인 실사가 없어야). 줄: 품목 · LOT · 상태(가용 · 검사대기)와 실물 수량(0 이상, 품목 단위의
자릿수 안). 더한 줄의 품목 · LOT 는 수불 줄과 같은 규칙. 확정: 작성 중인 실사 번호 하나.

**번호 규칙(PR B)** — 코드 · 이름(1 ~ 50자) · 머리 · 구분자 · 날짜 꼴 · 일련 자릿수 · 사용 여부. 칸의 꼴은 ADR 0016 의 표. 유형의 기본 규칙은 「사용 안 함」이 아니다.

**품목의 새 칸(PR B)** — LOT 관리(예 · 아니오, 비우면 유형의 기본값), 품목 유형(공통코드 `ITEM_TYPE` 의 다섯 — ADR 0019), LOT 번호 규칙(반제품 · 완제품만 — 비우거나 「사용」인 규칙 코드. 다른 유형은 비어야 한다), 기본 입고 · 출고 창고(비우거나 불량창고가
아닌 「사용」인 창고). 시트형 등록은 지금 시트의 규칙(이름 · 코드 둘 다, `Y`/`N`)을 그대로 따른다.

**창고의 새 칸(PR B)** — 불량창고(예 · 아니오, 비우면 아니오). 재고가 있는 창고는 이 표시를 바꾸지 못한다(상태가 바뀌므로).

**단위 사양(PR A)** — 기준 단위(자신이거나, 기준이 자신인 「사용」인 `UNIT` 값) · 배수(0 보다 큰 수, 소수 여섯째 자리까지, 기준이 자신이면 1) ·
소수 자릿수(0 ~ 3). 등록 뒤에는 자릿수만.

## ④ 결정

**정한 것**

- 재고를 세는 단(LOT 관리 품목만 LOT · LOT 하나 · 분할 · 병합 없음) · 음수 막음(지난 날짜 포함) · 저장 즉시 반영과 취소만 · 상태(불량은
  창고, 검사대기는 칸) · 할당은 조각 「작업지시」 · 수불 일자(지난 날 · 오늘, 마감 없음) · 실사(확정 때의 장부) · 품목의 기본 입고 · 출고
  창고 — 저자 판정(2026-11-05). ADR 0015.
- 전표 번호 `IV-YYYYMMDD-NNN` · LOT 번호는 「시스템 관리 › 번호 규칙」의 규칙으로(LOT 만) · 규칙마다 구분자(없음 · `-` · `_` · `.`, 대안은
  조각을 마음대로 늘어놓기) · 사 오는 품목은 거래처 LOT 를 반드시, 저절로 붙이는 것은 반제품 · 완제품만 — 저자 판정(2026-11-05, 구분자와
  사 오는 품목의 LOT 는 착공 PR 검토).
- 품목 유형에 부자재 `SM` · 소모품 `CS` 를 더한다 — 기본값 구매 · LOT 끔 · 검사 끔(대안은 원자재로 두고 LOT 만 끄기 · 두지 않기) —
  저자 판정(2026-11-05, 착공 PR 검토). ADR 0019. PR B 가 짓는다.
  실사 번호 `PI-…` · 샘플 규칙 · 수불 유형 · 조정 사유 — Claude 가 낸 안, 착공 PR 검토에서 저자가 본다. ADR 0016.
- 단위마다 기준 단위 · 배수 · 소수 자릿수, 같은 기준이면 다른 단위로 넣음 — 저자 판정(2026-11-05). ADR 0017.
- 바코드 · LOT 라벨은 하지 않고 후보 메뉴로 — 저자 판정(2026-11-05). ADR 0016 결과.

DB 는 PGlite(내 컴퓨터에서 도는 PostgreSQL)에 레포의 마이그레이션을 그대로 적용해 실제 SQL 을 돌린다 — 키가 필요 없다. `CLAUDE.md` 에 따라

**재고 계산의 시험 규칙**(PR C · E — 한 갈래의 시험이 다 지는 것)

- **R1 거절 시험**은 거절 뒤 그 전표의 줄 · 잔액 표 전체 · 전표 번호 일련 · LOT 일련이 거절 전과 같은지와, 거절한 줄 · 칸 · 모자란 수량을 본다.

- **R3** ② 의 보장마다, ③ 의 칸마다 맞는 꼴 하나와 틀린 꼴 하나 이상. 음수 검사는 적어도 오늘 · 지난 날짜(그 뒤에 나간 수불이 있는 것) ·
  같은 날 등록 차례 · 취소가 음수를 만드는 것 · 두 저장이 동시에 같은 재고를 쓰는 것.
- **R4 변조본** — 재고 계산의 보장마다(음수 검사 · 전표 단위 · 잔액 불변식 · 취소 한 번 · 불량창고 · 단위 자릿수) 그 검사를 지운 사본에서
